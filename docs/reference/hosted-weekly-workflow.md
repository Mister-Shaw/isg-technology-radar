# 每周更新与异动监测

由当前 Codex 任务的每周定时任务执行，Asia/Shanghai 周一09:00。首次为2026-09-28。本站不另设独立服务器定时器；任务在可执行的本机环境中进行采集、核验和发布。任务调度状态以 Codex 为准。

## 每次执行

1. 读取本站 `.openai/hosting.json`，复用现有公开站点和共享数据库。读取最新站点数据、站内编辑和上次成功批次，不用旧备份覆盖当前记录。研究文件 `data/research-2026.json`，媒体文件 `public/market-panel.json`，来源摘要 `public/sample-sources.json`，监测状态 `data/weekly-monitor.json`。执行入口可从同级 `source-expansion-2026-09-21`、`comparable-measures-2026-09-21` 的现有采集器及 `scripts/build-market-panel.mjs` 复用。
2. 以北京时间上一个完整周日为截止日；未成功采集不推进数据截止日。增量采集上次成功截止后的文档，并重查此前14天的可变目录和公告，月初额外回补上月。跳过已缓存的稳定正文，但重新请求动态目录；不可把旧缓存运行成功当作新增采集成功。现有历史脚本含固定日期、目录路径，运行前传入或调整本批截止和输出位置，核对结果日期；不直接重跑历史 merge/install 覆盖现库。
3. 市场风向保持 DOIT、C114、至顶、CBI 四家固定来源的全部新闻分母；技术、地域、芯片只筛分子。沿用统一标题分类和同源标题去重。保持所有主题及无技术命中的新闻。新来源先单列或回补完整历史，不能直接拼入旧趋势。官方、公众号、招采来源用于月度项目研究，不能混入媒体固定分母。公开访问受限时记录缺口，不绕过登录、验证码、付费或访问控制。
4. 月度研究覆盖12个技术主题，加海光、鲲鹏两条路线，共14个观察子项，按lib/hierarchy.js映射至5个父类；技术主题为：超节点、液冷、国产GPU、算力场（含AI一体机）、EDA、算力租赁、Token工厂、光交换机（严格OCS）、AI存储、AIDC、模块化数据中心、xPU/异构加速。xPU优先补采显式异构方案及服务器NPU/DPU/FPGA，不把普通CPU/GPU词汇自动纳入。重点海光CPU、海光DCU、鲲鹏CPU，角色分别识别。优先补买方/招标/中标/合同/验收，再用官网、新闻和公开公众号交叉核实。使用原始链接、项目编号、买方、实际事件日期、披露日期、采集日期及证据等级。转载只补来源；同项目不同阶段保留。回补旧事件不计本周新需求；无来源、未来事件、普通交换机和泛Token话题不凑数。
5. 核实金额单位、币种、税务与阶段，明细与异动判断保留预算、成交、合同、总投资口径。月度金额热力图按用户要求合并已核/待核与各类总额，不再按核验状态或金额类型拆图；复用combinedAmountRows按已知项目/标包取最新披露一次，区间保留上下限，按下限着色。单价、无金额、冲突、失效及多家候选报价合计等不可分配金额不计。合并披露额不称为实际成交额或市场规模，候选和估算不升格为成交；新阶段可能修订历史格子。保留用户编辑、ID、共享笔记和历史。
6. 对每个来源保存本批检索范围、页码/日期边界、成功/失败、分子/分母、去重前后数量及截止日。同步研究数据、媒体面板、来源摘要、来源目录和当前研究判断。未完月保留标记；月度图表按数据窗口新增月份，不把部分月与完整月直接比较。各类格子不设数量配额；来源摘要同步分类版本。采集完成后执行 scripts/refresh-taxonomy.mjs 重算当前全窗口的观察标签和分类清单，分类重算日期改为本批实际日期，不修改采集日期。父类新闻/事件/金额均取底层并集，不能累加子类；不得把历史重识别标为新增采集。新路线采购分母未建立时保持缺口。
7. 读取 `data/source-remediation.json` 的逐源缺口与协助清单，继续补采受限来源：优先公开目录和原文，动态正文用正常浏览器；原入口失败时追查地方采购、买方、上市公司及官方生态机构披露。商业API未授权保持原状态，不把公开替代稿标为API已接通。沐曦、合见、华理使用已实测公开栏目；摩尔线程正文正常浏览器可读，无需机械要求用户提供。确实遇登录、验证码、证书问题或原始附件缺失时才更新具体协助任务；不绕过限制。用户提供新证据后移除已完成的协助项。
8. 手动资料使用CSV/JSON结构化导入，保留日期、项目、标包、金额单位与类型。相同原文、明确项目编号及标包不重复新增；编号缺失有歧义时先补证；已存在记录通过编辑补证，禁止用旧文件覆盖新笔记。日期缺失不猜采集日；单位矛盾不计金额。行业评估和泛Token文章仅作参考，不能为凑量归入Token工厂或算力场。同步 `data/source-remediation.json` 与下载副本 `public/source-remediation.json`，分清研究补采结果与站内自动读取日志。

## 异动规则（初始监测阈值，可调整，非统计显著性结论）

- 热度：最近完整7天与此前完整28天比较，固定四媒体技术新闻占比绝对变化至少5‰、相对变化至少50%；本周或基线折算周均技术命中至少5条；至少2家媒体方向一致。两窗口每周新闻分母均至少200，且各来源覆盖完整。基线为0时按新出现处理，仍满足绝对变化、数量和跨来源条件。先检查来源发稿结构与分类规则是否变化，必要时标注为待解释。
- 项目：新增已核成交/合同单项至少1000万元，正式预算至少5000万元、项目总投资至少10亿元；分别提示，不相加、不当服务器收入。未核大额报道作为待核线索提示并明确证据状态。
- 重点路线：海光、鲲鹏的新增明确采购/成交/合同/投产/扩容、重大产品发布，以及重点项目取消、废标、终止、金额或状态冲突。海光CPU不能视为GPU。
- 采集：固定来源缺失、日期覆盖不足或同周全新闻量相对前4周周均下降50%以上，先作为数据质量异常，不解释为需求下降。
- 同一事件/同一规则/同一周只提示一次。上次已提示且未出现新阶段、新证据或风险变化的，不重复提示。

## 检查、发布和状态

2026-09-23手动执行的滚动批次见 `data/rolling-update.json`，原始响应和合并依据见同级 `weekly-runs/2026-09-23-manual`。后续读取最新滚动批次并同步其公开下载副本；本批按原截止9月20日回查，9月21—23日预览尚未纳入完整周。信息源以 `data/sources.js` 当前登记入口为准，已补熠知电子和云豹智能；入口可读与全量同步分开记录。沿用公开原文日期核对，DOIT模板datePublished异常时不得覆盖其可见文章日期；C114当天归档日期检查未通过的预览下轮再核。

先保存合并站内最新编辑后的本批研究文件，运行 `scripts/weekly-monitor.mjs --end YYYY-MM-DD --research 合并研究文件路径` 生成监测草稿（写到同级 weekly-runs；不改成功水位）。该文件可为研究对象或本站API备份结构。初次初始化使用 `--init --end 2026-09-20` 建立已知ID与历史基线，不发送历史异动。项目提示从上次成功截止后补齐，避免跳过失败周；本期新披露的历史事件可以提示，但必须标识历史事件/新披露，不能作为当期新需求。

运行相关数据检查、共享记录回归及构建；历史精确数值测试应对固定2026-09-20快照运行，新增周期检查使用守恒、范围、去重和完整性条件，不能为了通过而删除校验。核对月度、市场风向和来源清单一致，保持原图表。Sites工具发布到原网址，保持公开免登录，确认成功后再将本批状态、实际截止、成功时间及已提示ID写入成功台账。发布失败保留旧成功水位，报告失败和恢复步骤；不静默跳过。

异动提示在本Codex任务给出，包含技术/主体、变化值或阶段、比较区间、分子分母、金额性质、原文链接、证据强弱、业务判断和优先行动。无显著异动时仍更新数据与站点，在任务中保持安静。仅有重要异动、采集/发布失败或需要用户输入时主动通知。不要发送邮件或即时通信消息。

版本资料按既定联想项目目录归档，保留旧版、核对复制一致性。任务重试不得重复插入事件或重复发布相同内容。

若固定媒体仍有缺口，监测草稿 `complete=false`，本批即使发布部分成果也不推进全局成功水位；继续保存已提示ID，补齐后再推进。只有通知实际发出后，才把对应ID追加到 `notified_ids`。通知可合并同一事件展示，但保留不同标包/金额项，不能只按event_key删记录。
